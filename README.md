# 🎹 KeyBoopWin

**KeyBoopWin** — мощное приложение для Windows, которое автоматически исправляет раскладку клавиатуры, поддерживает голосовой ввод, перевод между русским и английским языками с азбукой Морзе, конвертер регистров и экранный переводчик.

## ✨ Возможности

### 🔄 Автоматическое исправление раскладки
- **Мгновенное исправление** при наборе текста в любом приложении
- Поддержка **русской** и **английской** раскладок
- **Ручное исправление** выделенного текста по горячей клавише (`Ctrl + [` / `Ctrl + ]`)
- Настраиваемые горячие клавиши для ручного исправления

### 🎤 Голосовой ввод
- Распознавание речи на **русском** и **английском** языках
- **Шумоподавление** с автоматическим обучением
- Регулировка **усиления микрофона**
- Предпросмотр уровня звука в реальном времени
- История распознанного текста с возможностью копирования

###  Переводчик
- Перевод между **русским** и **английским** языками
- **Азбука Морзе**: кодирование и декодирование текста
- Автоматическое распознавание ввода (текст или Морзе)
- Кнопка быстрой смены направления перевода
- Копирование текста, перевода и кода Морзе в буфер обмена

### 🔤 Конвертер регистров
- Быстрое преобразование текста в различные регистры
- Открытие по горячей клавише

### 📺 Экранный переводчик
- Перевод текста с экрана
- Активация по горячей клавише

### ⚙️ Настройки
- **Горячие клавиши** для всех функций:
  - Голосовой ввод (по умолчанию `F1`)
  - Переводчик (по умолчанию `F2`)
  - Конвертер регистров (по умолчанию `F3`)
  - Экранный переводчик (по умолчанию `F10`)
- **Спящий режим**: приостановка работы приложения для экономии ресурсов
- **Автозагрузка**: настройка запуска при старте Windows
- **Словари**: возможность загрузки собственных словарей или обновления с GitHub
- **Защита от конфликтов**: автоматическая проверка дублирования горячих клавиш

###  Системный трей
- Работа в фоновом режиме
- Быстрый доступ ко всем функциям через иконку в трее
- Уведомления о состоянии приложения

## Что касаемо словарей 📘

- ** Тут будут искажения в словах и ложные срабатывания, люди используют не более 400 слов в перписке ежедневно, и мои слова могут отличаться от ваших, поэтому возможно ложное срабатывание.
- ** К счастью, в папке программы вы можете обновить словарь и поправить неправильное слово, принцип следующий, если в ru.txt и в en.txt есть одно и тоже слово оно меняться не будет.
- ** Если слова нет в одном из словарей то слово поменяется пример "kjk" оно отсутствует в словаре en.ru, но есть в ru.txt оно поменяется на "лол".
- ** Если слова нет в словаре то программа сама не придумывает, она проигнорирует.

## 🚀 Установка

### Системные требования
- **Windows 10** (версия 1809 или выше) или **Windows 11**
- **.NET 8.0 Runtime**
- **Windows App Runtime 2.3.1**

### Установка через установщик
1. Скачайте `KeyBoopWin_Setup.exe` из раздела [Releases](https://github.com/C7AY/KeyBoopWin/releases)
2. Запустите установщик
3. Следуйте инструкциям мастера установки
4. Windows App Runtime установится автоматически, если он не установлен

### Ручная установка
1. Скачайте архив с последней версией из [Releases](https://github.com/C7AY/KeyBoopWin/releases)
2. Распакуйте в удобную папку
3. Установите [Windows App Runtime 2.3.1](https://learn.microsoft.com/windows/apps/windows-app-sdk/downloads) (если не установлен)
4. Запустите `KeyBoopWin.exe`

## 📖 Использование

### Автоматическое исправление раскладки
Просто начните печатать в любом приложении. KeyBoopWin автоматически определит, если вы набрали текст в неправильной раскладке, и исправит его.

### Ручное исправление
1. Выделите текст в неправильной раскладке
2. Нажмите `Ctrl + [` для перевода в русскую раскладку
3. Или `Ctrl + ]` для перевода в английскую раскладку

### Голосовой ввод
1. Откройте главное окно KeyBoopWin
2. Нажмите **Старт** для начала записи
3. Говорите четко в микрофон
4. Нажмите **Стоп** для завершения записи
5. Текст появится в поле распознавания

### Переводчик
1. Откройте Переводчик через трей или горячую клавишу (`F2`)
2. Введите текст для перевода
3. Перевод появится автоматически
4. Азбука Морзе отобразится в нижних полях

### Настройка горячих клавиш
1. Откройте **Настройки** через трей
2. Перейдите в раздел горячих клавиш
3. Нажмите **Изменить** и нажмите нужную комбинацию
4. Нажмите **Сохранить**
