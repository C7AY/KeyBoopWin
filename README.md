# 🎹 KeyBoopWin

**KeyBoopWin** — мощное и гибкое приложение для Windows, предназначенное для автоматического исправления раскладки клавиатуры и опечаток, голосового ввода, перевода текста (с поддержкой Азбуки Морзе и Двоичного кода), быстрого вызова таблицы редких спецсимволов и многого другого.

## ✨ Возможности

### 🔄 Автоисправление раскладки и умный Спеллчекер
- **Мгновенная смена раскладки** при наборе текста в любом приложении (RU / EN).
- **Умное исправление опечаток (`SpellingChecker`)**: использует алгоритм расстояния Левенштейна. Если вы допустили ошибку в 1 символ, программа аккуратно предложит подмену (только если вариант исправления ровно один и очевиден).
- **Ручное исправление** выделенного текста по горячим клавишам (`Ctrl + [` / `Ctrl + ]`).

### 🎤 Голосовой ввод (Vosk Engine)
- Локальное распознавание речи для **русского** и **английского** языков.
- **Встроенное шумоподавление (`NoiseSuppressor`)** с автоматической калибровкой при начале записи.
- **Точная регулировка усиления микрофона (Gain)** для тихих устройств.
- Индикатор уровня звука в реальном времени.

### 🌐 Универсальный переводчик (Текст + Морзе + Binary)
- Быстрый перевод между **русским** и **английским** языками.
- **Азбука Морзе**: двухстороннее кодирование и декодирование.
- **Двоичный код (Binary UTF-8)**: мгновенный перевод текста в 8-битные бинарные последовательности и обратно.
- **Умный автодетект**: программа сама понимает, что вы ввели — обычный текст, точки-тире Морзе или нули и единицы `01001000`.

### 🔣 Таблица спецсимволов и флагов (`SymbolsWindow`)
- Отдельное удобное окно с категориями редких знаков:
  - ✍️ **Типографика**: кавычки-елочки, тире, градусы, параграфы, эмодзи.
  - 📐 **Математика**: знаки не равенства, интегралы, суммы, бесконечность.
  - 🏛️ **Греческий алфавит**, 🏹 **Стрелки**, 💎 **Валюты**.
  - 🏳️ **Флаги стран**: СНГ, Европа, Америка и Азия.
- **Мои сохраненные символы**: добавляйте свои редкие знаки и удаляйте ненужные через контекстное меню.
- Копирование в буфер обмена в один клик через Win32 API.

### 🔤 Конвертер регистров & 📺 Экранный переводчик
- Быстрое изменение регистра выделенного текста.
- Перевод текста прямо с экрана по горячей клавише.

### ⚙️ Гибкие настройки и системный трей
- Глобальные горячие клавиши с **защитой от конфликтов** и дублирования.
- **Спящий режим**: быстрая приостановка работы программы для экономии ресурсов.
- **Автозагрузка**: запуск вместе со стартом Windows.

## 📘 Работа со словарями и орфографией

- **Принцип работы словарей**: если слово присутствует и в `ru.txt`, и в `en.txt`, оно не меняется. Если слово есть только в одном словаре (например, `kjk` отсутствует в `en.txt`, но есть в `ru.txt`), оно автоматически заменится на соответствующее слово (например, `лол`).
- **Защита от фантазий**: если слова нет ни в одном словаре, программа ничего не придумывает и проигнорирует его.
- **Умный спеллчекер**: если включена проверка опечаток, программа проверяет слова той же длины (±1 символ). Замена происходит **только при расстоянии Левенштейна = 1** и только если существует **ровно один** кандидатурный вариант, чтобы избежать ложных срабатываний (например, для короткого `прив` программа не будет угадывать между `привет` и `привык`).
- **Участие в разработке**: вы можете поправить словари прямо у себя в папке программы или создать Pull Request на GitHub с исправленными файлами `ru.txt` / `en.txt` 🫶.

## ⌨️ Горячие клавиши по умолчанию

| Функция | Комбинация по умолчанию |
| :--- | :--- |
| **Голосовой ввод** | `F1` |
| **Переводчик** (RU/EN / Морзе / Binary) | `F2` |
| **Конвертер регистров** | `F3` |
| **Экранный переводчик** | `F10` |
| **Таблица спецсимволов** | Настраивается в параметрах |
| **Ручной перевод в RU раскладку** | `Ctrl + [` |
| **Ручной перевод в EN раскладку** | `Ctrl + ]` |

## 🚀 Установка

### Системные требования
- **Windows 10** (версия 1809 или выше) или **Windows 11**
- **.NET 8.0 Runtime**
- **Windows App Runtime 2.3.1**

### Порядок установки
1. Скачайте архив `KeyBoopWin.zip` из раздела [Releases](https://github.com/C7AY/KeyBoopWin/releases).
2. Распакуйте архив в удобную папку.
3. Запустите `KeyBoopWin.exe`.
4. Если система затребует Windows App Runtime 2.3.1 или net 8.0, то она сразу же предложит его установить и отправит вас на официальный сайт скачать ее и установить.
